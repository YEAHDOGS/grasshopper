# Grasshopper — Roadmap

## Rev A (first run, 2027 projection)

- Sweep mode: beeper + haptic Geiger feedback, directional whip
- Map mode: Wi-Fi network inventory, RSSI-plotted dots, editable floor plan
- Base bands: 500 kHz–1.75 GHz SDR, 2.4 GHz Wi-Fi/BLE, sub-GHz/LoRa
- Free signature updates forever

## Pro tier

- 5 GHz Wi-Fi radio, extended cellular SDR coverage
- Tracker-tag ranging, evidence export

## Research (not promised for Rev A)

- Wi-Fi CSI person-tracking through walls (published research, not productized)
- Sharper auto-positioning from walk-the-house RF heatmaps
- IMSI-catcher / stingray classification
- IR night-vision camera detection (rev B diode)
- 13.56 MHz RFID/NFC coil (rev B, ~$0.40 BOM)
